---

### 📌 Project Overview
This lab upgrades the BiteBox website with better typography and layout structure.  
All pages are now linked to an external stylesheet and Google Fonts for a more professional look.

---

### ✨ What Was Added
- External CSS linked on all pages
- Google Fonts (Poppins, Montserrat, Pacifico, Great Vibes)
- Improved Hero sections with styled text
- Navigation with Cart icon
- Active link class on Home page
- Better structured buttons and sections
- Consistent header/footer across pages

---

### 📄 Pages Included

| Page    | File           | Key Features                          |
|---------|----------------|---------------------------------------|
| Home    | `index.html`   | Hero, features, dishes, reviews       |
| Menu    | `menu.html`    | Categories, menu cards, offer         |
| About   | `about.html`   | Story, mission, chefs, statistics     |
| Contact | `contact.html` | Info cards, form, map section         |
| Cart    | `cart.html`    | Cart table, order summary             |
| CSS     | `css/style.css`| External stylesheet                   |
