> BiteBox website styled with Google Fonts, hero backgrounds, buttons, and page-specific CSS for Home, Menu, About, Contact, and Cart.

---

### 📌 Project Overview
This lab applies real CSS styling across the BiteBox multi-page website.  
It includes CSS reset, navigation styles, hero backgrounds, typography, and button designs for all main pages.

---

### ✨ CSS Features Added
- CSS Reset & global font
- Navigation links + hover effect
- Home Hero (background image, title, buttons)
- Menu Hero styling
- About Hero styling
- Contact Hero styling
- Cart Hero + divider design
- Order / Explore Menu button styles with hover
- Google Fonts support (Montserrat, etc.)

---

### 📄 Pages Included

| Page    | File            | Styled Sections                |
|---------|-----------------|--------------------------------|
| Home    | `index.html`    | Hero, buttons                  |
| Menu    | `menu.html`     | Menu hero, categories          |
| About   | `about.html`    | About hero                     |
| Contact | `contact.html`  | Contact hero                   |
| Cart    | `cart.html`     | Cart hero + divider            |
| CSS     | `css/style.css` | Full stylesheet                |

---

### 🛠️ Skills Demonstrated
- External CSS linking
- Background images (`background-size: cover`)
- Pseudo-classes (`:hover`)
- Typography & font families
- Button styling & transitions
- Section-based CSS (`#home-hero`, `#menu-hero`, etc.)
- Multi-page consistent design
